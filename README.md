# GradientSimilarity-FedMeta

A Meta Learning Enhanced Gradient Similarity Driven Personalized Federated Learning Method with a Lightweight Neural Network for Multi Centre Liver Cancer Recurrence Prediction

## Overview

This repository contains the implementation of a novel personalized federated learning framework that combines meta-learning with gradient similarity-based client selection for multi-centre liver cancer recurrence prediction. The method utilizes a lightweight neural network architecture to enable efficient deployment across distributed healthcare institutions while preserving data privacy.

## Features

- **Personalized Federated Learning**: Client-specific model adaptation through meta-learning
- **Gradient Similarity-Based Selection**: Intelligent client selection mechanism based on gradient similarity metrics
- **Lightweight Neural Network**: Efficient architecture suitable for deployment in resource-constrained environments
- **Privacy-Preserving**: Data remains at local institutions while enabling collaborative learning

## Requirements

- Python >= 3.8
- PyTorch >= 1.9.0
- NumPy >= 1.19.0
- scikit-learn >= 0.24.0
- pandas >= 1.2.0

See `requirements.txt` for a complete list of dependencies.
